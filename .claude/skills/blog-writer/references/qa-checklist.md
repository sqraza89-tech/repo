# QA checklist (run before handing over)

## Facts and claims
- [ ] Every company fact matches the brand profile / confirmed-facts memory
- [ ] Every claim is in the approved-claims file, or is sourced to a named external source with a link
- [ ] Every case/proof item is in the proof library and described exactly as the library allows (anonymised where required)
- [ ] No never-name clients anywhere, including alt text and file names
- [ ] No invented statistics. If a number would help but isn't sourced, put it in Open questions

## Brand
- [ ] Voice matches the profile; no banned words from the jargon/avoid list
- [ ] Headline is plain and keyword-first (no puns, idioms or metaphors)
- [ ] Spelling standard applied (grep for the other variant)
- [ ] Ambassador/author names and titles exactly as in the profile

## Funnel
- [ ] ICP and stage stated in the frontmatter
- [ ] CTA matches the stage, target page is live
- [ ] Next-stage link included

## AEO/SEO
- [ ] Opening answers the title alone
- [ ] Question H2s with direct first sentences
- [ ] FAQ + JSON-LD present and valid JSON
- [ ] Title ≤ 60 chars, meta 140–160 chars

## Delivery
- [ ] File name `YYYY-MM-DD-<brand>-blog-<slug>.md`, frontmatter present, `## Next steps` checklist at the end
