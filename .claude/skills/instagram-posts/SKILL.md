# Instagram posts — Sana Defies Gravity

## Step 1 — Load the brand

1. Read `Reference/brands/sanadefiesgravity.md` and `Projects/aerial-yoga/context.md`.
2. Never use xLoop or TekRevol material, phrasing or tone here.
3. If the post depends on a `TODO` (schedule, class length, mentioning Komal, booking method),
   ask first. Don't invent class times or prices.
4. If `Projects/aerial-yoga/content-calendar.md` exists, pull the rows for the requested dates.

## Step 2 — Pick the format

| Type | Use when | Shape |
|---|---|---|
| Reel | reach, showing movement | 1s visual hook + on-screen text → 3–5 shots → caption with a soft CTA. 7–20s |
| Carousel | teaching, saves | cover with a promise ("3 things to know before your first aerial class") → 1 idea per slide → CTA slide |
| Class announcement | schedule, new slots, handover | what · where · when · level · how to book |
| Student / progress | social proof | the moment (first inversion), the student's words, with consent only |
| Behind the scenes | trust, personality | rig check, playlist, tea ritual at Asana, Sana's own training |
| Stories | daily presence | polls ("ever been upside down?"), Q&A, countdown to class, reshares |

## Step 3 — Write

- Hook in the first line and on-screen text, in the student's own words (see the ICP table)
- Speak to fear: beginners worry about strength, flexibility and going upside down. Reassure
- Tailor to the studio: Dynamik = strength and skills; Asana = calm, ritual, self-care
- No medical claims, no weight-loss or body-shaming framing
- CTA: book at the studio / DM me (only booking routes confirmed in the profile)
- Tag the studio accounts once confirmed; 5–10 hashtags mixing local and niche
- Captions: short lines, line breaks, 0–3 emojis

## Step 4 — Output

For each post: format · goal · on-screen text / shot list · caption · hashtags · suggested
posting day. For a week's plan, a table first, then the posts.
Offer a matching WhatsApp version for the studio groups when it's a class announcement.
Save weekly batches to `Projects/aerial-yoga/posts/YYYY-MM-DD-week.md`.
