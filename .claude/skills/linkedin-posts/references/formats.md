# LinkedIn post formats

Skeletons, not scripts. Fill with the brand's own words and approved proof.

## Service / offering post
Approved by Sana for xLoop (2026-09-30) after four rewrites. Default for any service post, any brand,
unless that brand's profile says otherwise.

```
[Hook naming the buyer — "Run a power company? NEPRA's rules apply to you."]
[Business case in one line — why they need it. No fear, no invented stats.]

→ [Offering 1] — [one-line benefit]
→ [Offering 2] — [one-line benefit]
→ [Offering 3] — [one-line benefit]

[CTA] · [certifications/credentials right next to it]
```
Proof stories go in the caption or first comment, not in the visual. Process: one line or none.

## Ambassador thought leadership
```
[A specific observation from real work — a number, a moment, a mistake]
[Why it matters to <ICP>]

1. …
2. …
3. …

[What I'd do / what I'd ask your team]
[Question to the reader]
```

## Blog teaser
```
[The single most useful finding from the post, stated plainly]
[Who it's for + what they'll be able to decide after reading]
[3 bullets of what's inside]
Full post: [link] (or "link in first comment")
```

## Proof / delivery (anonymised)
```
[Client type + situation — "A financial services firm running RPG on IBM i…"]
[What we did — 2–3 lines]
[Outcome — only if in the proof library]
[Who else this is relevant for] → [CTA]
```

## Carousel (5–8 slides)
Slide 1 hook (≤ 8 words) · slides 2–6 one idea each (≤ 25 words) · last slide CTA + credentials.
Give Omais/design a 1-line visual note per slide.

## Video (25–30s, 5–6 scenes)
Scene · on-screen text (≤ 8 words) · voice-over line · visual note. One idea per scene.

## Occasion / greeting
2–4 lines, warm, brand-appropriate. No product pitch. Visual note for design.
Check the date is right for the country (PK / UAE / other) — Islamic holidays move with moon sighting,
so write "Eid Mubarak" posts to be scheduled on confirmation.
