# Search & AEO checklist

## Search Console (last 3 months vs previous 3)
- Clicks, impressions, CTR, avg position — total and **non-brand only** (filter out the brand name)
- Top queries by impressions with CTR < 1% → title/meta rewrites
- Pages at position 3–15 → refresh candidates (hand to blog-writer refresh mode)
- Queries that match an ICP pain but land on the wrong page → internal linking / new page
- Indexing: pages not indexed, and why
- Countries: is traffic from target markets?

## Technical SEO spot-check
- Titles/metas unique, canonicals, one H1, sitemap and robots.txt, 404s, redirects
- Structured data present (Organization, Service, FAQPage, Article, BreadcrumbList) — check with the
  Rich Results Test in the browser

## AEO / AI answer visibility
1. Write 8–12 prompts the ICPs would actually ask an AI (from the ICP pains in the brand profile),
   e.g. "Who can do a NEPRA IT/OT compliance audit in Pakistan?", "How do I modernize COBOL to Java?"
2. Run them where possible: web search (Google AI Overviews show in results), Perplexity and
   ChatGPT search in the browser if the user is signed in and agrees. Don't create accounts.
3. For each: is the brand mentioned? cited with a link? which competitors are? which sources get cited?
4. Output a table: prompt · brand present (Y/N) · competitors present · cited sources · gap.
5. Actions: pages that need an answer-first section, FAQs, a comparison table, or third-party
   presence (directories, partner pages, PR) that engines cite.

Also check: robots.txt doesn't block GPTBot/ClaudeBot/PerplexityBot/Google-Extended (unless that's
a deliberate decision), key facts are in HTML text, not images.
