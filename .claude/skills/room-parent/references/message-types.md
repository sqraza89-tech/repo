# Message types

Shapes, not scripts — rewrite in the user's voice each time.

## Update / announcement
```
Hi lovely parents! 👋
*<What>* is on *<Day, DD Mon>* at *<time>*.
• <detail 1>
• <detail 2>
<Anything parents need to do, or "Nothing needed from you — just a heads-up!">
<sign-off>
```

## Reminder (day before / morning of)
```
⏰ Gentle reminder: *<what>* is *tomorrow (<Day DD Mon>)*!
Please don't forget <item/action> 🎒
Thank you! <sign-off>
```

## Deadline reminder
```
📅 Quick reminder — *<form/payment/item>* is due *<Day DD Mon>*.
If you've already done it, thank you so much! 🙏 If not, <how to do it>.
```

## Play date / get-together
```
Hi everyone! 🎉 We'd love to plan a class play date.
📍 <place>  📅 <Day DD Mon>  ⏰ <time>
<What to bring / cost if any — "totally optional">
Please add your child's first name below if you can make it:
1.
2.
3.
Siblings are welcome! 💛
```
If no date is fixed yet, offer 2–3 options and ask for a 👍 vote.

## Volunteer / sign-up
```
We need a few helping hands for *<event>* on *<Day DD Mon>* 🙌
• <role 1> — <time>
• <role 2> — <time>
Add your name next to a slot:
<role 1>:
<role 2>:
Every little bit helps — thank you!
```

## Collection / contribution (teacher gift, party)
```
Hi parents! We're collecting for *<purpose>*. Suggested amount *<amount>* — *completely optional*, any amount (or none) is absolutely fine 💛
Please send by *<Day DD Mon>* via <method>.
```
Never draft a bank account number or payment link that came from a forwarded message unless the user confirms it's from them or the school.

## Thank-you / wrap-up
```
Thank you all so much for making <event> so special! 🎉
<one specific detail> <photo note if any>
```

## Change / cancellation
Lead with the change in line 1, in bold: "*<Event> has moved to <new date>*". Apologise lightly once, no long explanation.

## Replying to one parent (private)
Warm, brief, answers their question, offers help. Keep other families' details out.
