# TekRevol image prompts (ChatGPT / GPT Image)

For the v6 guidelines decks (`deck-v6/`). Each prompt makes a background or image a designer can drop into a specific slide. Mood: the shared moodboard (molten red-orange, chrome and pearl, soft focus, glossy 3D objects, deep charcoal) applied to the brand idea "structured chaos" and "better with every layer".

## How to use
- Paste one prompt per chat message. Ask for 3 to 4 variations, pick the best, then say "same style, new variation" for more
- ChatGPT outputs 3:2 landscape; crop to 16:9 in PowerPoint (Picture Format > Crop > Aspect ratio 16:9)
- Put the image behind the slide content (right-click > Send to Back). Keep the text areas the prompt leaves empty
- For the **Cyan** deck, add this line to any prompt: `Add a subtle secondary glow of ice cyan (#3EC5D1), much smaller than the orange.`
- Never use generated people as real TekRevol staff in public material; they are mood images only

## Checklist before using an image
- One orange focal point only; regenerate if orange appears in several places
- No blue or purple casts (the category color we are stepping away from)
- No garbled text, fake logos or warped hands
- Leave the planned text area clean; add a 30 to 40% charcoal overlay if text becomes hard to read
