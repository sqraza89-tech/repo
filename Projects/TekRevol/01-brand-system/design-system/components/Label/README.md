# Label

Mono uppercase labels give TekRevol its engineered rhythm: an eyebrow above every section heading, and tags on cards.

- Eyebrow: `tr-label` in `accent-ink`, `label` style (JetBrains Mono 12px, +0.08em, uppercase), `space-2` above the heading
- Tag: add `tr-tag` for an `accent-soft` fill with the `notch-sm` cut
- Muted metadata: `tr-label--muted` in `ink-muted`
- A slash separates parts: "LAYER 03 / ARCHITECTURE". Two to four words

Do not: use labels as headings, write sentences in them, or stack more than four tags on one card.
