# Molten

The Molten gradient field and reeded-light treatment: TekRevol's backgrounds for heroes, campaign visuals, end cards and social.

- `tr-molten`: soft radial field of Molten, Core Red and Haze light on carbon. Heat always flows from deep red to pale haze
- `tr-reeded`: an overlay of fine vertical ribs, like fluted glass, that splits the light into layers. Layer it over `tr-molten` or a molten-glass image
- Content on top: the **white** logo, a headline in `ink` (carbon theme), or a Button. Keep the area behind text calm; add a carbon scrim if contrast drops below 4.5:1
- In production, swap the CSS field for an approved molten-glass render when you want more depth

Do not: put body text or the full-color logo on it, add other hues, or use more than one Molten field per screen.
