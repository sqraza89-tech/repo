# Button

One primary button per view, for the action the page exists for; everything else is secondary or a link.

- **Primary** (`tr-btn tr-btn--primary`): `accent` fill, `on-accent` (carbon) text, square with the `notch-sm` cut top-right. Hover `accent-hover`, pressed `accent-pressed`
- **Secondary** (`tr-btn--secondary`): transparent, `line-strong` border, `ink` text
- **Link** (`tr-btn--link`): `accent-ink` text, underline on hover
- Text in the `button` style, sentence case, verb first: "Talk to an engineer", "Get a project estimate"
- Focus: 2px `focus-ring` with a 2px offset

Do not: use pill shapes, white text on orange, two primary buttons side by side, or vague labels like "Learn more" and "Submit".
