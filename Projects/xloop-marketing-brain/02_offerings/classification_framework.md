# Offering Classification Framework

The brief requires that capability, solution, product, commercial offer, proven implementation
and experimental work are never blurred. This file defines the categories; the inventory applies
them.

---

## The six categories

| Category | Definition | Test | Example from xLoop |
|---|---|---|---|
| **CAPABILITY** | Something xLoop can technically do | Can we staff it and ship it? | Computer Vision |
| **SOLUTION** | A capability aimed at a defined business problem | Does it name a problem, not a technology? | Branch operations monitoring |
| **PRODUCT** | A named, repeatable, packaged offering | Does it have a name, a page and a repeatable scope? | xVision |
| **COMMERCIAL OFFER** | Something a client can actually buy, with a scope and a price | Could sales quote it this week? | NEPRA Compliance Audit |
| **PROVEN IMPLEMENTATION** | Delivered, substantiable, evidenced | Can we name the client, the outcome and the source? | 30 MW wind IPP IT/OT audit |
| **EXPERIMENTAL / EMERGING** | In development or validation | Is there a delivery record? If no — this | xCrowdIQ |

**The chain that matters:** capability → solution → product → commercial offer → proven
implementation. Marketing may lead with any link, but must never *imply* a link it does not have.
Most of the credibility risk in the current material comes from presenting a CAPABILITY with
statistics that imply a PROVEN IMPLEMENTATION.

## Maturity scale

| Level | Meaning |
|---|---|
| **M1 — Concept** | Documented, not built |
| **M2 — Built** | Working, not sold |
| **M3 — Sold once** | One paying engagement or pilot |
| **M4 — Repeatable** | Sold and delivered more than once, scope stabilised |
| **M5 — Scaled** | Multiple clients, standard commercials, referenceable |

## Evidence strength scale

| Grade | Meaning |
|---|---|
| **A** | Named client, measured outcome, client-approved for public use |
| **B** | Named client, measured outcome, **not** approved for public use — internal only |
| **C** | Anonymised client, described outcome, no measurement method |
| **D** | Described capability, no client, no outcome |
| **E** | Claim with no traceable basis found — `EVIDENCE REQUIRED` |
| **X** | Claim that may belong to a third party — **do not publish** |

**Nothing below grade C may carry a numeric outcome in public material.**
**Nothing at grade X may be published at all until ownership is established.**

---

## Public-use status

| Status | Meaning |
|---|---|
| **PUBLIC — APPROVED** | Already published by xLoop, or explicitly approved |
| **PUBLIC — ANONYMISED ONLY** | May be described without naming the client |
| **INTERNAL** | Sales/board use only, never published |
| **RESTRICTED** | Contains client-confidential or personal data; access controlled |
| **UNKNOWN** | No approval record found — treat as INTERNAL until confirmed |
