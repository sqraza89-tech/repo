# Leading Indicators

Lagging indicators (pipeline, revenue) tell you what happened. Leading indicators tell you whether
it will happen. With a 3–9 month sales cycle for ICP 1 and no CRM, xLoop needs leading indicators
more than most.

Each is rated for whether it can be measured **today**.

---

## Tier 1 — Strongest predictors of qualified pipeline

| Indicator | Why it predicts | Measurable today |
|---|---|---|
| **Inbound contacts naming a specific problem** | The clearest possible intent signal; passes qualification Gate 2 on arrival | ✅ Manual, if the form asks |
| **AI Readiness Assessment completions** | Self-selected, self-qualifying, and it hands you their situation | ❌ Tool not built |
| **Scoping call requests** | One step from an opportunity | ✅ Manual |
| **NEPRA letter reply rate** | Direct, attributable, short-cycle | ✅ **Today** |
| **Non-brand organic clicks to pillar/service pages** | The buyer with a problem is finding you | ✅ **Today** — currently ~0 |
| **Repeat visits from a target-account domain** | Active evaluation | ⚠️ Partially |

## Tier 2 — Useful, indirect

| Indicator | Why it matters | Measurable today |
|---|---|---|
| Pillar page sessions (excluding careers/bootcamp) | Relevant reach | ⚠️ Needs segmentation |
| Service page → case study → contact path completions | Full consideration journey | ⚠️ GA4 path exploration |
| Target-account engagement on LinkedIn | Account warming | ⚠️ Manual |
| AI answer-engine referrals | New discovery channel. **54 sessions referred by GPT** in one quarter — small but real and growing | ✅ **Today** |
| Gated asset downloads by ICP-matching organisations | Mid-funnel interest | ⚠️ Manual |
| Inbound partner or referral introductions | Path C health | ⚠️ Manual |
| Search impressions on **commercial** queries specifically | Visibility where it matters | ✅ Today, if segmented brand/non-brand/commercial/research |

## Tier 3 — Diagnostics only, never headline

Reach, followers, likes, impressions in aggregate, publication counts, average position, bootcamp
applications. Useful for understanding *why* a Tier 1 number moved. Never reported as performance.

## The brand/non-brand/commercial/research split

The single most useful analysis xLoop can run with existing tools. Classify every Search Console
query into four buckets:

| Bucket | Example | What it tells you |
|---|---|---|
| **Brand** | `xloop`, `xloop digital`, `x loop` | Brand recall — currently ~98% of all clicks |
| **Brand confusion** | `xloop loan app`, `xloop loans` | Wrong-entity traffic; exclude |
| **Commercial** | `ai security assessment`, `nepra compliance audit`, `data modernization consulting` | **The number that matters — currently ~0 clicks** |
| **Research** | `agent hospital china`, `cio decision framework e-clinical`, `evaluate the transportation company grab` | Impressions without commercial value |

Tracking the commercial bucket alone would tell xLoop more about whether its positioning is
working than any dashboard it could buy.

## Early-warning indicators

Signs the strategy is failing, worth watching deliberately:

| Warning | Means |
|---|---|
| Non-brand clicks stay at zero while publishing continues | Content is aimed at the wrong queries. **Stop and re-aim.** |
| Impressions rise while clicks stay flat | Ranking for questions nobody buys from. Already happening |
| Leads arrive but sales rejects them | The qualification gates or the targeting are wrong |
| NEPRA page traffic without inbound contacts | The offer or the CTA is not landing — or the Category-1 doubt is reaching buyers |
| All pipeline arrives via Path C (referral) | Marketing is not generating demand, only confirming it |
| Content volume rises, qualified leads flat | The ToFu trap the Q3 review already identified |

## Reporting cadence

| Frequency | What | To whom |
|---|---|---|
| **Weekly** | Inbound contacts, NEPRA replies, scoping calls, new signals on watch accounts | Marketing + Sales, 10 minutes |
| **Monthly** | Non-brand clicks by bucket, pillar page sessions, assessment completions, content-to-pillar mapping compliance | Head of Marketing |
| **Quarterly** | Full funnel, qualified pipeline (once measurable), leakage review, positioning check | Leadership |

**Rule for every report:** state what is measured, what is estimated, and what is not measurable
yet. A report that quietly presents activity as outcome is worse than no report, because it removes
the pressure to build the measurement.
